## How to submit

1. Keep your work in **your own GitHub repository** — one repository for the whole course is easiest, since every homework builds on the same app.
2. Before you push, make sure this passes with no errors:

   ```bash
   npm run check
   ```

   It runs the type check, the linter and the formatter check. We set it up in class 1.
3. Send the link to your repository (and later, your deployed URL) as instructed in class.

## Rules

- **Never commit `.env`.** It contains secrets. Commit `.env.example` instead, with the same keys and placeholder values.
- **AI assistants are welcome** — but you must be able to explain every line you hand in.
- Stuck? Ask early — in class or by email. A homework you got help with beats one you didn't hand in.
