# Class 01 — Examples

A playground app for the concepts from class 1. Every file under `app/` has comments explaining **what** it does and **why** — read them alongside the running app.

```bash
npm install
npm run dev
```

| URL                                                                            | Shows                                      |
| ------------------------------------------------------------------------------ | ------------------------------------------ |
| [/](http://localhost:3000)                                                     | The simplest possible page                 |
| [/routing](http://localhost:3000/routing)                                      | File-based routing                         |
| [/routing/anything](http://localhost:3000/routing/anything)                    | Dynamic route with `params`                |
| [/routing/nested](http://localhost:3000/routing/nested)                        | Nested layout + Client Component counter   |
| [/routing/nested/deeper](http://localhost:3000/routing/nested/deeper)          | A deeper page sharing the same layout      |
| [/rendering/static](http://localhost:3000/rendering/static)                    | Static rendering (prerendered at build)    |
| [/rendering/dynamic](http://localhost:3000/rendering/dynamic)                  | Dynamic rendering (per request)            |
| [/styling](http://localhost:3000/styling)                                      | Tailwind, `@theme`, CSS file, inline style |

To compare static and dynamic rendering, use a production build — the build output marks each route as `○ (Static)` or `ƒ (Dynamic)`:

```bash
npm run build
npm run start
```

See the [class README](../README.md) for the full concept list, exercises and links.

> `AGENTS.md` / `CLAUDE.md` are generated by `create-next-app`. They tell AI coding assistants to read the Next.js docs bundled in `node_modules/next/dist/docs/` — handy, because most AI training data is for older Next.js versions.
